## Accessibility

- Uses a semantic `<button>` element by default.
- Loading state sets `aria-busy="true"`; the button is disabled while loading.
- Prefer `softDisabled` over `disabled` for controls users should still be able
  to discover and focus (e.g. pagination arrows) — it uses `aria-disabled`
  instead of the native attribute, keeping the control in the tab order.
- Icon-only buttons require an `aria-label`.
