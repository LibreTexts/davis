## Origins

Davis grew out of the need for a shared, accessible UI layer across LibreTexts
products that were each reinventing buttons, inputs, and dialogs — with
inconsistent accessibility. Consolidating those patterns into one system
reduced duplication and raised the accessibility floor everywhere at once.

## Why React and Vue

LibreTexts ships products in both React and Vue. Rather than pick one and strand
the other, Davis keeps design decisions in a framework-agnostic core and binds
them into both — so every team gets the same system.

## Naming

The system is named **Davis**, continuing LibreTexts' convention of naming
tooling after people and places connected to the project's roots.
